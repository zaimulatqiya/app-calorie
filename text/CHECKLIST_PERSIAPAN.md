## 🚨 EMERGENCY CHECKLIST

### ❌ Jika Aplikasi Crash:
1. [ ] Tetap tenang, jangan panik
2. [ ] Restart aplikasi dengan cepat
3. [ ] Sambil restart, jelaskan ke audience
4. [ ] Jika tidak bisa fix cepat, gunakan:
   - [ ] Screenshot yang sudah disiapkan
   - [ ] Video demo yang sudah direcord
5. [ ] Lanjutkan presentasi dengan slides

### ❌ Jika Proyektor Bermasalah:
1. [ ] Check kabel VGA/HDMI
2. [ ] Tekan Windows + P (duplicate/extend)
3. [ ] Restart laptop (last resort)
4. [ ] Jika tidak bisa fix:
   - [ ] Presentasi dari laptop langsung
   - [ ] Audience mendekat (jika memungkinkan)

### ❌ Jika Lupa Script:
1. [ ] Tarik napas dalam
2. [ ] Lihat slide sebagai panduan
3. [ ] Jelaskan dengan bahasa sendiri
4. [ ] Fokus pada poin utama
5. [ ] Jangan terburu-buru

### ❌ Jika Pertanyaan Sulit:
1. [ ] Minta waktu untuk berpikir
2. [ ] Jika tidak tahu: "Pertanyaan bagus, saya perlu riset lebih lanjut"
3. [ ] Offer untuk follow-up via email
4. [ ] Jangan mengada-ada jawaban

### ❌ Jika Melebihi Waktu:
1. [ ] Skip slide yang kurang penting
2. [ ] Percepat bagian yang sudah jelas
3. [ ] Fokus pada demo dan hasil
4. [ ] Summarize conclusion dengan cepat
