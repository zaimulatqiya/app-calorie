  1️⃣  DATA COLLECTION & LABELING
      Pengumpulan dan pelabelan gambar

  2️⃣  DATA AUGMENTATION
      • Rotation (±20°)
      • Flip (horizontal)
      • Zoom (20%)
      • Brightness adjustment

  3️⃣  TRANSFER LEARNING
      • Pre-trained ImageNet weights
      • Fine-tuning last layers
      • Freeze early layers

  4️⃣  EVALUATION
      • Accuracy, Precision, Recall
      • Confusion Matrix
      • Cross-validation

## 🎨 DESIGN GUIDELINES SUMMARY

### **Color Palette:**
```
Primary:    #4CAF50 (Green)
Secondary:  #388E3C (Dark Green)
Accent:     #C8E6C9 (Light Green)
Text:       #212121 (Dark Gray)
Background: #FFFFFF (White)
```

### **Fonts:**
```
Headings:   Montserrat Bold (32-48pt)
Subheading: Montserrat SemiBold (24-28pt)
Body:       Open Sans Regular (18-20pt)
Code:       Fira Code (16pt)
```

### **Layout Rules:**
```
• Margins: 1 inch all sides
• Max 5-7 bullet points per slide
• Min font size: 18pt
• Consistent alignment
• White space is good
```

### **Visual Elements:**
```
• Use icons/emoji for visual interest
• Screenshots for demo
• Charts for data
• Diagrams for architecture
• Photos for food items
```

## 💡 POWERPOINT TIPS

### **Creating Slides:**

1. **Use Master Slide**
   - Set up template once
   - Consistent header/footer
   - Logo placement

2. **Animations (Optional)**
   - Keep it simple
   - Fade in for bullet points
   - No distracting effects

3. **Transitions**
   - Subtle transitions only
   - Fade or None
   - Consistent throughout

4. **Images**
   - High resolution (min 1920x1080)
   - Compress for file size
   - Proper attribution if needed

5. **Charts/Graphs**
   - Use PowerPoint built-in tools
   - Clear labels
   - Readable from distance
