## 🎬 RECORDING TIPS

### **Before Recording:**

1. **Practice Run**
   - Do 2-3 dry runs without recording
   - Time yourself
   - Smooth out any awkward parts

2. **Script Preparation**
   - Don't memorize word-for-word
   - Know key points
   - Speak naturally

3. **Environment**
   - Quiet room
   - No interruptions
   - Good lighting (if webcam)

---

### **During Recording:**

1. **Voice:**
   - Speak clearly and slowly
   - Project your voice
   - Vary your tone (not monotone)
   - Smile (it shows in your voice)

2. **Mouse Movement:**
   - Move slowly and deliberately
   - Circle important elements
   - Don't shake mouse nervously

3. **Pacing:**
   - Don't rush
   - Pause after important points
   - Give time for viewers to see

4. **Mistakes:**
   - If you make a mistake, pause 3 seconds
   - Start that section again
   - Edit out mistakes later

---

### **After Recording:**

1. **Review:**
   - Watch the entire video
   - Check audio quality
   - Check visual quality
   - Note any issues

2. **Edit (if needed):**
   - Cut out mistakes
   - Add intro/outro cards (optional)
   - Add background music (optional, low volume)
   - Add subtitles (optional but helpful)

3. **Export:**
   - Format: MP4 (most compatible)
   - Resolution: 1920x1080 (Full HD)
   - Frame rate: 30fps
   - Bitrate: 5-10 Mbps

## 🎯 USAGE DURING PRESENTATION

### **When to Use Video Backup:**

1. **Aplikasi crash** dan tidak bisa restart cepat
2. **Internet down** (jika aplikasi perlu internet)
3. **Laptop freeze** atau bermasalah
4. **Proyektor tidak kompatibel** dengan live demo
5. **Time constraint** - video lebih cepat dari live demo

### **How to Use:**

```
1. Acknowledge the issue calmly
   "Sepertinya ada masalah teknis.
   Saya sudah menyiapkan video backup."

2. Open video file
   (Should be ready on desktop)

3. Play video
   "Video ini menunjukkan demo lengkap
   aplikasi yang seharusnya kita lihat."

4. Narrate along (optional)
   Add commentary as video plays

5. Continue presentation
   Move to next section after video
```

## 💡 PRO TIPS

### **Recording:**
- Record in one take if possible (more natural)
- If mistake, pause 3s and continue (edit later)
- Speak to an imaginary audience
- Pretend you're teaching a friend

### **Audio:**
- Use headset mic for better quality
- Record in quiet room
- Test audio before full recording
- Speak 6-12 inches from mic

### **Visual:**
- Use cursor highlighting (some tools have this)
- Zoom in on important details
- Keep cursor movements smooth
- Don't move too fast

### **Editing:**
- Less is more - don't over-edit
- Keep it natural
- Cut out long pauses
- Maintain good pacing

## 🚨 TROUBLESHOOTING

### **Problem: Audio not recording**
**Solution:**
- Check mic permissions
- Select correct audio input
- Test with different app
- Use external mic

### **Problem: Video laggy**
**Solution:**
- Close other applications
- Lower recording quality
- Use hardware encoding
- Upgrade recording software

### **Problem: File too large**
**Solution:**
- Reduce resolution (1280x720)
- Lower bitrate
- Compress with HandBrake
- Use H.265 codec (smaller)

### **Problem: Video won't play on other PC**
**Solution:**
- Use MP4 format
- Use H.264 codec
- Install VLC player
- Convert to different format
